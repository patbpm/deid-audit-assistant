De-identification and audit assistant for clinical text

Finds identifiers in free-text notes, replaces them consistently, flags what it is unsure about for a person, and keeps an audit trail of every change.

How it works

DetectMuse Spark lists identifiers
Verifydoubtful spans re-checked
Name check"Hunter" the surname or the word?
Replacedates shifted, one fake name per real name
Red-teamreads the clean note, looks for clues
Audit + reviewevery change traced; a person decides

Fails closed: if a model reply cannot be read, the note is marked NOT CLEANED instead of being passed through.

An assistant for human review. It is not a compliance certification, and it gives no medical advice.
